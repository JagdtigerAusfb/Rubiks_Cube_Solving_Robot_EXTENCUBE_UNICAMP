# RAIDEN

This repository contains everything related to the Rubik's Cube solving robot, **Raiden** and its second version: **Tupa**. This project was developed as an extension project at the State University of Campinas (UNICAMP).

## Introduction

The goal of this project was to develop a simple Rubik's Cube solving robot using accessible, easy-to-use, and relatively inexpensive components.This was achieved by building our first bot: the RAIDEN, named after the Japanese god of thunder, shown in the picture below. After its completion, the second iteration, the TUPÃ, named after Tupi-Guarani mythology, also shown in the picture below, was built using more expensive components, with the goal of minimizing completion times.

The RAIDEN achieved a record time of 1.82 seconds using a 19-move solution, running at a speed of 750 µs.
